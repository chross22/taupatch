# Join covariate sets from two products onto the same points

Join covariate sets from two products onto the same points

## Usage

``` r
join_covariate_sources(x, y)
```

## Arguments

- x:

  an `sf` POINT covariate object

- y:

  another `sf` POINT covariate object

## Value

`x` with `y`'s variable columns joined on nearest point and date
