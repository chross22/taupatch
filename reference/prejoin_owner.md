# Which fetched product carries a covariate

Which fetched product carries a covariate

## Usage

``` r
prejoin_owner(per_dataset, covariate, type)
```

## Arguments

- per_dataset:

  a list of `sf` POINT objects

- covariate:

  a covariate name

- type:

  the step type, for the error message

## Value

the index of the object holding it
