# Covariate columns a derivoce step reads

Covariate columns a derivoce step reads

## Usage

``` r
derivoce_inputs(spec, entry)
```

## Arguments

- spec:

  a normalized step specification

- entry:

  the matching
  [`derivoce_covariates()`](https://camilleross.org/taupatch/reference/derivoce_covariates.md)
  entry

## Value

character vector of covariate column names the step needs present
