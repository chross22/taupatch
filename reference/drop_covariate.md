# Remove a covariate from the product carrying it

Remove a covariate from the product carrying it

## Usage

``` r
drop_covariate(per_dataset, index, covariate)
```

## Arguments

- per_dataset:

  a list of `sf` POINT objects

- index:

  which object to take it from

- covariate:

  the covariate to drop

## Value

`per_dataset` without that column
