# Stage columns for a species, excluding precomputed totals

Stage columns for a species, excluding precomputed totals

## Usage

``` r
species_stage_pool(header, column_prefix, single_only = FALSE)
```

## Arguments

- header:

  column names of the database

- column_prefix:

  the species' column prefix in the database

- single_only:

  restrict to individually resolved stages, including aliases

## Value

character vector of column names
