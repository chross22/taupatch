# Write covariate summaries and month-by-year heatmaps

Write covariate summaries and month-by-year heatmaps

## Usage

``` r
write_covariate_summary(covariate_means, config)
```

## Arguments

- covariate_means:

  a data frame from
  [`covariate_monthly_means()`](https://camilleross.org/taupatch/reference/covariate_monthly_means.md)

- config:

  a config list, as returned by
  [`load_config()`](https://camilleross.org/taupatch/reference/load_config.md)

## Value

`NULL`, invisibly
